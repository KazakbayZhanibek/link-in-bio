Проект: C:\Users\Janchik\Desktop\zhanibek-links
Репозиторий: https://github.com/KazakbayZhanibek/link-in-bio.git
Существующий zhanibek-portfolio не изменён.
Сайт опубликован: https://kazakbayzhanibek.github.io/link-in-bio/
GitHub Pages настроен на GitHub Actions. Ваш компьютер и локальный сервер не нужны.

ГДЕ МЕНЯТЬ ССЫЛКИ
Один файл: src/config.ts.
- website.url — публичный HTTPS-адрес вашего основного сайта.
  Указан ваш сайт: https://kazakbayzhanibek.github.io/JanibekPortfolio/
  http://127.0.0.1:5173/ — адрес только вашего компьютера, его не публикуем.
- contact.telegram.url и description — Telegram и подпись.
- contact.email.url — mailto:ваш-адрес; description — видимый адрес почты.
- github.url — профиль GitHub.
- name, introduction, about, location, footer — имя, знакомство, короткий рассказ,
  возраст/город и нижняя фраза. Тексты основаны на личном портфолио.
- meta — заголовок, описание и текст картинки для отправки ссылки.

null или пустая строка отключают соответствующую ссылку.
Локальные адреса, IP-адреса и неподдерживаемые протоколы не становятся кнопками.
Если оба контакта пустые, блок сообщает, что контакты появятся позже.
После правки config.ts перезапустите локальный сервер либо соберите сайт заново:
конфигурация используется и браузером, и при предварительной генерации HTML.

ЛОКАЛЬНЫЙ ЗАПУСК
Нужен Node.js 22. Откройте терминал в папке проекта:
  npm ci
  npm run dev -- --port 5174 --strictPort
Откройте адрес, напечатанный Vite. Обычно http://127.0.0.1:5174/.
Это адрес для просмотра на вашем компьютере, не для шапки Instagram.

СБОРКА
  npm run build
Готовые файлы находятся в dist/.
Для локального просмотра сборки:
  npm run preview
Не открывайте index.html двойным щелчком через file://.

ОБНОВЛЕНИЕ САЙТА НА GITHUB PAGES
1. В репозитории KazakbayZhanibek/link-in-bio откройте:
   Settings > Pages > Build and deployment > Source > GitHub Actions.
2. Отправьте исходники проекта в ветку main, включая .github/workflows/pages.yml,
   package-lock.json и tools/. Не отправляйте node_modules/ и dist/:
   они уже исключены через .gitignore.
   Для отправления изменений, из папки проекта:
     git add .
     git commit -m "Обновить личную страницу ссылок"
     git push origin main
3. Во вкладке Actions дождитесь зелёного результата «Публикация страницы».
   Workflow сам выполнит npm ci, сборку и загрузку dist в GitHub Pages.
4. Откройте сайт: https://kazakbayzhanibek.github.io/link-in-bio/
5. Этот публичный адрес можно поставить в Instagram.

Дальше каждый push в main обновляет страницу. Есть и ручной запуск:
Actions > Публикация страницы > Run workflow.
Отдельный сервер, база данных, Vercel и платный хостинг не нужны.
Просто загрузить исходный index.html без сборки недостаточно: сборку делает Actions.
Не переключайте Source на Deploy from a branch / main: в main лежат исходники,
не готовый сайт. Это приводит к белому экрану. Оставляйте GitHub Actions.

ПРЕВЬЮ И МЕТАДАННЫЕ
HTML предварительно сформирован на этапе сборки. Ссылки и текст доступны без JS.
Favicon: public/favicon.svg. Картинка 1200×630 создаётся при сборке из config.ts.
GitHub Actions автоматически передаёт адрес Pages в SITE_URL: canonical, og:url
и og:image получают абсолютные публичные адреса без ручной настройки.
Для другого хостинга задайте meta.publishedUrl в src/config.ts, со слешем в конце.
При обычной локальной сборке без опубликованного URL og:image относительный;
перед публикацией вне GitHub Pages заполните publishedUrl и пересоберите.
Мессенджеры могут кэшировать старую картинку после обновлений.
